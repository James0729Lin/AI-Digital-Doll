# AI Digital Doll（AI 桌面數位人偶）

一款 Windows 桌面應用程式：

1. **捏人系統**：從性別開始，自訂 3D 人物的臉型、五官、身材（胸、臀、腿、手臂等）與服裝，並存檔。
2. **桌面人偶**：捏好的人物會以 3D 角色的形式出現在 Windows 桌面上，自由走動、坐在視窗上、做出各種動作。
3. **AI 代理人**：綁定 ChatGPT / Claude / DeepSeek / Gemini / Grok 或本地模型，對人偶下指令，由人偶轉交給 AI，再用語音或對話泡泡回答，並依回答內容做出對應動作與表情。
