# AI 聊天：測試說明

這一版可以讓桌面角色連上 AI 聊天，回答會顯示在她頭上的對話泡泡裡，並依內容做出不同的表情與手勢。

## 1. 綁定 AI

1. 在角色身上按右鍵 →「**AI 設定…**」。
2. 按「**新增…**」選一個服務：

   | 服務 | 需要 | 說明 |
   |---|---|---|
   | Claude | API 金鑰（console 的 API Keys 頁面） | 預設模型 `claude-opus-5-5` |
   | ChatGPT | OpenAI API 金鑰 | 模型可按「取得清單」挑選 |
   | Gemini | Google AI Studio 金鑰 | 有免費額度 |
   | DeepSeek / Grok | 各自的 API 金鑰 | |
   | Ollama / LM Studio（本地） | 不用金鑰，但要先安裝並下載模型 | 完全免費、離線 |

   「如何取得？」連結會打開該服務的金鑰頁面。**費用由各服務直接向你收取**；本程式不收費。
3. 貼上金鑰，按「**取得清單**」選模型（或直接輸入模型名稱）。
4. 按「**測試連線**」，看到「連線成功！」就完成了。
5. 可以新增好幾個服務，按「設為預設」選平常用哪一個（清單中有 ★ 的）。
6. 下方可以改角色的名字與個性，AI 會用這個身分回答。

金鑰只存在這台電腦，並用 Windows 的資料保護功能（DPAPI）加密，換一台電腦或另一個 Windows 帳號都無法讀取。

## 2. 聊天

- **雙擊角色**，或右鍵 →「聊天…」，會在角色下方出現輸入框。輸入後按 Enter。
- 等待回答時，角色會做思考的動作，泡泡裡出現「・・・」。
- 回答會一個字一個字出現，角色同時開口說話，依內容換表情、做手勢（揮手、點頭、拍手、比讚、數數、鞠躬、聳肩…）。
- 回答中按「停止」或 Esc 可以中斷。
- 輸入框左邊可選這次要問哪個 AI；也可以打「**@名稱 問題**」臨時指定，例如 `@claude 幫我潤稿`。
- 直接叫她做動作會馬上執行：「揮揮手」「跳一下」「跳舞」「鞠躬」「拍手」「伸懶腰」「坐下」「去睡覺」。

## 3. 測試清單

| # | 測試項目 | 預期結果 |
|---|---|---|
| A1 | 沒設定就聊天 | 角色聳肩並說要先設定 AI，同時打開 AI 設定 |
| A2 | 測試連線 | 正確金鑰顯示「連線成功！」與一句回覆；錯誤金鑰顯示金鑰有誤 |
| A3 | 取得模型清單 | 列出該帳號可用的模型，點選後填入 |
| A4 | 一般對話 | 打招呼時揮手；道歉時鞠躬；開心的事會拍手或歡呼；不同回答的動作不一樣 |
| A5 | 連續對話 | 第二個問題接著前面的內容回答（記得剛剛聊過什麼） |
| A6 | 中斷 | 回答到一半按「停止」，文字停住、角色停止說話 |
| A7 | @指定 | 設兩個服務，用「@名稱」指定，泡泡左上角顯示回答的服務名稱 |
| A8 | 動作指令 | 輸入「揮揮手」「坐下」「去睡覺」，角色立刻照做 |
| A9 | 網路中斷 | 拔網路再問：角色聳肩說連不上 |
| A10 | 本地模型 | 用 Ollama（例如 `ollama run qwen2.5`）也能聊天並有動作 |
| A11 | 泡泡位置 | 泡泡跟著角色頭頂；角色在螢幕邊緣時泡泡不會跑出螢幕 |
| A12 | 說話時不亂跑 | 聊天時角色停在原地、面向你；泡泡消失後才繼續走動 |

## 4. 已知限制

- 還沒有語音（TTS／語音輸入），只有文字泡泡。
- 全域快捷鍵（Ctrl+Alt+Space 叫出輸入框）尚未完成。
- 聊天紀錄只在這次執行期間保留，關閉程式後會清空。
- 捏身材做出的角色還沒有臉部表情（VRM 角色才有）；手勢與動作都會做。
