# 捏身材原型：Windows 測試說明

這一版新增「捏身材」畫面。可以在素體（只穿貼身內衣）狀態下調整整體與各部位身材，並存檔。

> 目前捏好的身體**還不會**變成桌面上走動的角色（需要先做骨架綁定，是下一步）。桌面上仍是 Godette。

## 開啟方式

- 在桌面角色身上按 **右鍵 → 捏身材…**
- 或從系統匣圖示按右鍵 → **捏身材…**

捏人畫面是一般視窗，可以縮放、移動。按 **回到桌面** 或關閉視窗，都會自動存檔並回到桌面角色。

## 操作

| 操作 | 方式 |
|---|---|
| 旋轉角色 | 在左側 3D 畫面按住左鍵拖曳 |
| 上下移動鏡頭 | 按住右鍵拖曳 |
| 縮放 | 滑鼠滾輪 |
| 快速視角 | 左上角：正面 / 側面 / 背面、全身 / 上半身 / 下半身 |
| 調整身材 | 右側分頁：整體、胸、腰・腹、軀幹、臀・屁股、手臂、腿、體型範本 |
| 更多滑桿 | 開啟「進階模式」 |
| 左右分開調 | 取消「左右對稱」（手臂、腿會出現左、右兩個滑桿） |
| 單一滑桿恢復預設 | 滑桿右上角的 ↺ |
| 復原 / 重做 | 最多 50 步 |

## 測試清單

| # | 測試項目 | 預期結果 |
|---|---|---|
| 1 | 開啟 | 右鍵「捏身材…」後切換成一般視窗，出現穿著深色內衣的女性素體，介面為中文 |
| 2 | 拖曳滑桿 | 身材即時改變、不卡頓（請特別注意是否順暢） |
| 3 | 性別 | 拉到「男」時變成男性體型，且只穿短褲 |
| 4 | 胸、腰、臀、屁股、手臂、腿 | 各分頁的滑桿都會改變對應部位 |
| 5 | 身高 | 左上角與滑桿旁顯示的公分數會跟著改變 |
| 6 | 左右對稱 | 取消後只調整左手臂，只有一邊變粗 |
| 7 | 體型範本 | 「體型範本」分頁的各種體型都有效果，可以混合 |
| 8 | 膚色 / 內衣顏色 | 點色塊可以換顏色 |
| 9 | 復原 / 重做 / 隨機 / 全部重設 | 都正常運作 |
| 10 | 存檔 | 按「回到桌面」後再開「捏身材…」，身材保留 |
| 11 | 回到桌面 | 回到透明桌面模式，角色照常走動，滑鼠可穿透 |
| 12 | 高解析度螢幕 | 125% / 150% 縮放下文字大小正常、不模糊 |

有問題請截圖回報。如果覺得哪個滑桿的效果不明顯或怪怪的，也請告訴我是哪一個。
