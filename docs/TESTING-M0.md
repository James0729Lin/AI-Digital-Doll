# M0 技術驗證：Windows 測試說明

這一版只驗證最基本、風險最高的幾件事：**透明桌面視窗、滑鼠穿透、載入 3D 角色、角色在工作列上走動與被拖曳**。還沒有 AI 對話、語音和捏人。

## 1. 下載

1. 開啟本專案 GitHub 頁面上方的 **Actions** 分頁。
2. 點選最新一次、狀態為綠色勾勾的 **Build**。
3. 在頁面最下方的 **Artifacts** 下載 `AIDigitalDoll-windows-x64`（需先登入 GitHub）。
4. 解壓縮到任意資料夾（例如桌面），**整個資料夾要保留**，不能只拿出 exe。

## 2. 執行

- 執行資料夾中的 `AIDigitalDoll.exe`。
- 程式尚未做程式碼簽章，Windows 可能跳出「Windows 已保護您的電腦」：點 **其他資訊** → **仍要執行**。
- 若防毒軟體攔截，請告訴我是哪一套防毒軟體。

## 3. 結束程式

- 在角色身上按 **滑鼠右鍵** → **結束**。
- 或從右下角系統匣（可能收在「^」裡）的圖示按右鍵 → **結束**。

## 4. 測試清單

請逐項測試，把結果（✅ / ❌ + 說明）回報給我。有問題時，**截圖或用手機錄影**最有幫助。

## 5. 請一併提供的資訊

- Windows 版本（設定 → 系統 → 關於）
- 顯示卡型號
- 螢幕數量、解析度與縮放比例（例如 1920×1080、125%）
- 工作列位置（下方 / 左右 / 上方）、是否自動隱藏

## 6. 已知限制（這一版刻意未做）

- 只在主螢幕活動，不會跨螢幕
- 動作是程式即時產生的基本動作，之後會再擴充與調整
- 角色大小、走動頻率還不能調整（M1 設定頁）

## 7. 若畫面異常

如果角色背後是**黑色或白色方框**，代表你的顯示卡驅動不支援這種透明視窗。請回報顯示卡型號，我會加上備援模式。
